# Local Codex workspace

## Project instructions
- Treat requests to create code or files as authorization to act. Start creating the requested files immediately and make sensible assumptions for missing details.
- Do not ask for confirmation or permission for routine file creation, edits, builds, or running commands inside this workspace.
- Run the result, inspect errors, and fix them before reporting. Keep progress messages and final reports concise.
- Ask a question only when essential information cannot be reasonably inferred or the requested action would cause destructive changes outside this workspace.
- Keep generated project files under this workspace unless the user explicitly gives another destination.
- Shell: commands run in PowerShell 7 on Windows. Use `pwsh` (the `powershell` command is also available through a shim). Do not use bash syntax such as `$powershell -Command`.
- Never overwrite an existing file with placeholder text. Read a file first, then edit only the parts that need to change.
